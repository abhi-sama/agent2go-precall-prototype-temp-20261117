# Triage Labels

The skills use five canonical triage roles. This file maps those roles to the label strings used in this repository's GitHub issue tracker.

| Label in `mattpocock/skills` | Label in this repository | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue |
| `needs-info` | `needs-info` | Waiting for more information from the reporter |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation or judgment |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill mentions a canonical role, use the corresponding GitHub label from this table.
