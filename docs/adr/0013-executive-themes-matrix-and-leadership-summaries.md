# Executive themes, the topic-by-region matrix and leadership summaries are aggregate-only, shared by one library, and re-authorized on open and export

Ticket 13 (#14) gives the Executive portfolio, molecule, disease-area and study theme cards, a topic-by-region matrix with trend arrows, source-linked leadership summaries that can be saved and exported, and scoped natural-language organisational analysis. It builds on the Executive overview (ADR 0009, explicit scope and small-group suppression) and the Director's insight rules (ADR 0011).

## Decisions

- **Same door as the overview.** The Executive holds `aggregate.read` and no `source.records.read`, so RLS returns no response rows. Migration 011 adds SECURITY DEFINER functions that start from `app.exec_units()` (the explicit executive scope, empty for anyone else) and return counts, never rows: `exec_theme_counts` (current and prior window at cell, theme, region and group level in one query), `exec_trend_status`, `exec_threshold_definition`, and `exec_theme_records` (responses, only for an Executive who also holds `source.records.read`).
- **One library, two callers.** `backend/libs/a2g_exec_analysis` computes theme cards and the matrix and applies small-group disclosure. The API Lambda (dashboard, leadership summaries) and the agent (organisational chat) both call it, so a chart, a summary and a chat answer cannot disagree about what is hidden. The trend verdict is evaluated in the database by the Director's rule (`app.emerging_thresholds` / `app.emerging_status`): one rule for every persona.
- **Disclosure.** A count of 1 to 4 is withheld and carries no value. In the matrix, each region column keeps complementary suppression against its denominator, and a region's denominator against the group total. A theme card is the sum of its row of the matrix, so a card's counts are withheld whenever any cell of its row is withheld. No arrow or share is drawn from a withheld count (`WITHHELD`), and a region or group with fewer than the approved minimum of responses gets `INSUFFICIENT_SAMPLE` instead of a trend. With record-level permission nothing is withheld.
- **Citations.** An aggregate-only Executive cannot open records, so a theme card cites the set of responses it rests on: an `AGGREGATE` citation naming the theme, facet value, window and (when disclosable) the size. Only an Executive with explicit record-level permission also gets `RECORD` citations (response id and excerpt). Aggregate citations open no record; the chat citation query refuses them.
- **Approved thresholds.** The rule's numbers come from `app.emerging_thresholds()`. The API reports whether an administrator approved the rule as a governed definition (`emerging-topic-rule`, seeded as approved v1) and which version, so the matrix says "approved" only when it is.
- **Leadership summaries** follow the pre-call brief pattern (ADR 0009): the Lambda gathers evidence (already suppressed) and turns it into plain facts, each tied to a citation; the agent writes the prose and may cite only those ids (uncited statements and statements with unsupported figures are dropped by code); the agent saves the item to FE DynamoDB (ADR 0005). Items share the briefs table under `SUMMARY#<id>` with the same narrow reader and writer roles, so no new infrastructure is needed.
- **Re-authorization.** Opening, listing and exporting re-check access against the summary's own scope: the caller must still be an Executive with aggregate access, every territory the summary covers must still be in their explicit scope (else `Forbidden`, with no document and no audit row), and a summary built with record-level material is refused once that permission is withdrawn. Export writes an id-level audit event (`leadership_summary.exported`). Staleness is flagged when newer data is loaded or the scope changed.
- **Natural-language analysis** reuses the chat path. The agent gets two Executive tools (`get_org_themes`, `get_region_topic_matrix`) over the same library. Sample limitations are deterministic: the runtime runs the tools itself when the model skipped them, streams a final "Sample limitations:" paragraph, emits a `sample_limitations` event, and persists them with the turn. Only unsuppressed counts become facts.
- **Logging** carries ids, counts and enums only: no themes, names, response text or tokens.

## Consequences

- Seeded Executives hold one region each, so the matrix has one column until an administrator grants more explicit executive scope (tests do this with a temporary assignment). The mock adapter demonstrates four regions.
- Differencing across two different partitions of the same total (for example, a week against a month) remains out of scope, as in ADR 0009.
- Follow-ups: an audit event for aggregate reads (not just exports), a dedicated table for generated outputs if the briefs table's retention policy diverges, Executive chart visuals in chat, and Executive evaluation golden questions in the evaluation panel (ticket 18).
